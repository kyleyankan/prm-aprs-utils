# The APRS Incident Feeder: slide deck

The club talk about the Incident Feeder: 11 slides with speaker notes.

- `index.html`: open it in a browser to read every slide with its notes. It is a plain copy for
  reading, not the presenting view (no click-through, no animation), and it loads its fonts from
  Google Fonts.
- `slides/`: one file per slide, in the order listed in `deck.json`. Each holds one `<section>`;
  its `<aside>` is the speaker notes.
- `deck.css`: the look every slide shares (the GCARC theme colours: navy, gold titles, white text).
- `banner.png`: the Gloucester County Amateur Radio Club banner on the title slide, taken from the
  club's PowerPoint theme.

The deck is written and presented in Claude (a Slides artifact); these files are a copy of it as of
the commit that added them. After editing the deck there, copy the files here again and rebuild
`index.html` so the two do not drift apart.

The newsletter article that goes with it is in `../article/`.
