# APRS projects (K3YLE)

- `aprs-pi/` — turns county dispatch, 511 traffic and NWS weather feeds into APRS objects; runs on a
  Raspberry Pi. Start with `aprs-pi/README.txt`; `aprs-pi/ARCHITECTURE.md` explains how the services
  fit together, with diagrams, and where each feed's data comes from.
- `aprs-mapimage/` — Docker service that draws APRS map pictures for e-paper displays and dashboards.
  Start with `aprs-mapimage/README.md`.

`HANDOFF.md` has the goals, architecture, decisions and open tasks; `CLAUDE.md` has the working
rules for Claude Code.
