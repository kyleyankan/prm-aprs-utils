WHAT GETS SENT, AND WHEN

Sent only when it needs sending

THE SENDER’S RULES

New, changed or killed

Sent on the next poll.

Unchanged

Repeated every 26 minutes, to stay alive on maps.

Below the minimum importance

Held back, and killed if it is already on the air.

IMPORTANCE LEVELS

Critical

Tornado warning, entrapment, hazmat. Also a bulletin.

High

Building fire, rescue, a crash that closes the road

Medium

Other fires, crashes, road closures, weather warnings

Low

Alarms, disabled vehicles, roadwork, weather watches

The 26-minute repeat keeps objects on maps without filling APRS-IS with copies. Every object is rated from its name and the wording of its text, and the operator picks the lowest level that is sent. Most of the traffic is roadwork, which is rated low, so raising the minimum to medium cuts the object count by about nine tenths. Three more rules run by themselves. An object whose source has been silent for two hours is taken off. When a county dispatch feed and a 511 feed report the same crash, only the more important one is sent. And anything critical also goes out as a bulletin, BLN1 to BLN3, so radios that show messages but no map still get it.
